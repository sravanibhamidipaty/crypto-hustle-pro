# Screenshots

Add these files here so the links in the main README resolve:

- `home.png` — the home page: title, search bar, and the list of coins as clickable links with prices
- `detail.png` — a coin's detail page: title, icon, description, algorithm, and stats table
- `chart.png` — the 30-day price chart on a detail page (stretch)
- `not-found.png` — the catch-all "There's nothing here!" page for bad URLs
- `demo.mov` — a short screen recording of the full app (browse, click into a coin, view the chart, hit a bad URL)

## How to capture on macOS
- Screenshot of a region: Cmd + Shift + 4, then drag
- Screen recording: Cmd + Shift + 5, choose Record Selected Portion

## Demo video note
GitHub does not embed local `.mov` files via a relative path. To show the demo:
1. Open your repo on github.com and edit the README (or open an issue/PR).
2. Drag `demo.mov` into the text box; GitHub uploads it and generates a
   `https://github.com/user-attachments/assets/...` link.
3. Paste ONLY that link on the blank line under the "### Demo" heading in the main README.
